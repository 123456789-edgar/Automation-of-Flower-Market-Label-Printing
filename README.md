# Automation-of-Flower-Market-Label-Printing
To automate the flower market labeling process by transitioning from manual Bartender template printing to a fully integrated SAP Crystal Report design that allows direct barcode and label printing from SAP.

#Background Information.

In Bartender software: a software used in processing and packaging industries for example in supermarkets to identify and distinguish different products, a machine in form of a label printer is being used to print the labels or stickers which are then sticked on the item.
The item is uniquely identified and tied to that sticker.

In most enterprises, like a carton manufacturing industry, boxes are made for specific clients unto which unique products like flowers will be packed inside those boxes.

And to distinguish one box product from another, will be difficult in considerate of the scenario where the box was packed and sleeved hence the label process comes in handy.

The label process is usually done manually translating the details which would have been obtained from another software then using those details to generate labels.

In most comapnies/ organizations, they use softwares like SAP Business One, NetSuite, Microsoft Dynamics 365 Business Central which have this information captured in one way or another. For instance, in SAP, the labelling information is already captured in the Sales Order screen which has all information as per client specification.

This information include details like:
1. Customer Name
2. Variety Name
3. Length of Variety
4. PackRate
5. Linecode
6. Delievry Date
7. Drop Off Point et cetera

This same information is used manually to key onto Bartender to generate a label with visuals as attached.
